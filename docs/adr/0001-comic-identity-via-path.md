# Comic 身份锚定资源位置键

Comic 的 `comicId` 由规范化后的**资源位置键**派生（SHA1），而非文件内容哈希。

- **Local library**：位置键为规范化磁盘路径（与历史行为一致）。
- **Remote library**：位置键为规范化 WebDAV 资源 URL（含稳定的 scheme/host/path 约定，由 core 定义）。

同一位置键始终对应同一 Comic；移动、重命名或更改远程 URL 会生成新 `comicId`。Library sync 按所属 Library 对齐；不会仅凭内容自动迁移身份。

我们选择位置锚定，因为在个人库场景下，位置即用户心目中的「这本在哪」；扫描 diff 简单，且能区分同内容的不同副本。内容哈希虽能在移动后保留身份，但需要全量读内容、处理重复副本与元数据合并，成本更高，也与「按 Library root 镜像对齐」模型不契合。

远程纯流式阅读不落整本时，仍以远程 URL 为身份锚点；本地缩略图缓存仅为派生数据，不参与 `comicId`。

若未来要支持「移动后保留进度与元数据」，应显式引入迁移或内容指纹策略，而不是在位置哈希上打补丁。多 Library 与 WebDAV 根模型见 ADR-0008。
