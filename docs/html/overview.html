Lab 范围与阶段

术语见仓库 GLOSSARY.md（MD3E design system / Lab / Pilot / Cutover）。

三阶段

阶段 含义 本仓库现状

Cutover 生产 Baseline UI 迁到 MD3E，收双轨 未开始

目录结构

路径 内容

md3e/patterns/ 场景组合（无 Riverpod / 领域 import）

design-system/ 冻结归档（Lab 不以 MASTER 为入口，ADR-0030）
app/lib/shared/ui/ 生产 Baseline Fluent UI（仍为主壳）
